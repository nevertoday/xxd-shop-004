# 🦁 XXD Shop 004｜ベーカリーシリーズポスター

### 大きく、近く、おいしそうに。新作ひとそろいで、ひとつのブランドの世界

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <strong>日本語</strong> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

**ベーカリーのポスターを1枚でも、新作ひとそろいでも。大きく、近く、おいしそうに、ひと目で同じ店だとわかるように。**
シリーズでは、まずキーポスターを1枚作ってあなたの確認を取ります。残りは文字・色調・店のアイデンティティを受け継ぎ、レイアウトは1枚ごとに変えます。

| ひと目で分かる | |
|---|---|
| **渡すもの** | 商品画像または商品名（複数可）、店名かロゴタイプ、載せたい価格 |
| **受け取るもの** | ベーカリーのポスター1枚、または同じトーンでレイアウトが毎回違う新作シリーズ |
| **スタイルの特徴** | 巨大なクローズアップ · 朝の暖かく明るい光 · ブランドグラフィックとしての商品名 · 雑誌風の手書きメモ · ポスターごとに新しいレイアウト |
| **向いている用途** | パン、ケーキ、クロワッサン、タルト、クッキー、月餅。ベーカリーの新作や季節シリーズ |

> **インストールしたら、こう言うだけ：**
>
> /xxd-shop-004 ピスタチオのとろけるクロワッサン。3:4 のポスターを作って

## 解決すること

ベーカリーの新作告知には、よくある失敗が2つあります。1枚ずつはきれいなのに並べると4つの別の店に見える。あるいは統一感はあるけれど、全部同じテンプレートでパンが違うだけ。

**Shop 004** のルール：**ポスターごとにレイアウトは変えてよいが、文字の個性・色調・ブランドアイデンティティは共有する。**

1枚だけのポスターにも使えます。商品は大きく近く、いちばんおいしそうな食感（層、気泡、伸び、とろけるフィリング、アイシング）を、夜明けのパン屋のショーウィンドウのような光で拡大します。

## シリーズの作り方

1. 商品をまとめて渡します。写真を複数、フォルダ、または名前をいくつか。
2. 絵コンテを書きます。1品1枚、それぞれ違うレイアウト（背面の巨大文字、縦積み、特大の1品、散らした群像、縁から入る材料…）で、同じものを続けません。各品の味、価格、ステッカーはその品だけのものです。
3. 絵コンテと1枚目のポスターを見て、文字・色・店のアイデンティティを確認します。
4. 残りを作ります。キーポスターの文字の個性、色調、アイデンティティを受け継ぎます。

商品1つでもセットにできます。各ポスターは、その商品に本当にある食感を見せます。キーポスターがずれていたらそれだけを作り直すので、後の画像に誤りが引き継がれません。

## 用意するもの

- **商品画像または商品名**（必須）：写真があれば、断面やフィリングは写真どおり。何も足しません。
- **店名かロゴタイプ**（シリーズでは強く推奨）：シリーズをひとつにまとめます。
- **価格・「毎日焼きたて」・受賞・創業年**（任意）：言ったときだけ載せます。

## 使い方

### ステップ 1：インストール（1回だけ）

```bash
git clone https://github.com/nevertoday/xxd-shop-004.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-004" ~/.claude/skills/xxd-shop-004
```

Codex を使う場合は、同じフォルダを `~/.codex/skills/xxd-shop-004` にリンクしてください。インストール後は AI アシスタントのセッションを再起動します。

### ステップ 2：やりたいことを普通の言葉で言う

```text
/xxd-shop-004 ピスタチオのとろけるクロワッサン。3:4 のポスターを作って
/xxd-shop-004 ~/Desktop/autumn-launch の新作4品をシリーズに。店名は Maiye Bakery
/xxd-shop-004 商品はアールグレイのシフォン1つだけ。3枚セットで、1枚ずつ違う食感を見せて
```

覚えるフラグはありません。サイズや枚数など決めていないことは一度にまとめて質問され、次回は前回の設定を再利用できます。

### ステップ 3：そのあと何をするか

1. 商品画像と説明を読み、まだ決まっていないことだけを質問します。サイズは用途から、ピクセル数付きで提案します。
2. シリーズでは、まず絵コンテとキーポスターを見てもらい、確認のあとで残りを作ります。
3. サイズごとに構図を新しく作り、別の画像から切り抜くことはありません。
4. 納品前に1枚ずつ確認します。商品は変わっていないか、文字のつづりは正しいか、渡していない数字はないか。通らないものは報告して作り直します。
5. PNG を `~/Desktop/xxd/xxd-shop-004/` の下の新しいタスクフォルダに保存し、パスを伝えます。

## よくある質問

**ベーカリー以外の商品にも使えますか？**

ベーカリー向けに作られています。ほかのカテゴリは [001](https://github.com/nevertoday/xxd-shop-001) か [009](https://github.com/nevertoday/xxd-shop-009) を試してください。

**何が必要ですか？**

3つです。① Claude Code や Codex など、Skills に対応した AI アシスタント。② 画像を生成できるモデル。アシスタント内蔵の画像生成、または Codex に設定したモデルプロバイダーで Responses API 経由で画像を生成するもの（既定は GPT Image 2）。③ Pillow 入りの Python 3.11 以上（`pip install pillow`）。

**お金はかかりますか？商用利用できますか？**

Skill は無料でダウンロードできます。画像生成の費用はあなた自身のモデルアカウントに請求されます。本プロジェクトは PolyForm Noncommercial ライセンスです。個人の学習・研究・テストには使えますが、ショップ運営、受託制作などの商用利用には事前に作者の書面による許可が必要です。末尾の「ライセンス」を参照してください。

**画像の大きさは？**

比率か正確なピクセル数を指定できます。実際のサイズはモデルが返したとおりで、こっそり拡大することはなく、ファイル名に本当のピクセル数が書かれます。

**画像内の文字に誤字は出ますか？**

AI の画像では、ときどき文字を間違えたり、ブランド名の横に ® のような小さな記号を足したりします。納品前に1枚ずつ拡大して確認し、通らないものは作り直します。このページの作例はすべてその確認を通っています。

**価格や販売数をでっち上げませんか？**

しません。価格、仕様、産地、販売数、受賞、認証など事実に見えるものは、あなたが提供したものか、商品にはっきり読める文字からだけ取ります。それ以外は載せず、「¥XX」の仮置きもしません。

**たくさんの商品を一度に処理できますか？**

できます。商品画像のフォルダを渡してください。1枚の画像に商品1つ、サイズと文字は一度だけ質問され、ある商品の事実やコピーが別の商品に混ざることはありません。

## 原則

- **スタイルは忠実に：** この Skill の背後には成熟した商業デザインのプロンプトがあります（[原文プロンプト](references/original-prompt/zh-CN.md) · [英語の参考訳](references/original-prompt/en.md)）。Skill はそれを書き換えたり、独自の色やアートディレクションを足したりせず、あなたの商品、サイズ、文字、事実をモデルに渡すだけです。
- **商品をデザインし直さない：** 商品画像があれば、形、色、パッケージの文字、ロゴは写真どおりです。
- **あなたの事実だけ、** そして商品はそれぞれ独立。ほかの商品、以前の結果、作例から何も借りません。
- **本物の PNG ビットマップ。** SVG やコードで描いた絵を画像として出すことはなく、実行のたびに新しいタスクフォルダを作ります。
- シリーズで共有するのは文字の個性・色調・ブランドアイデンティティだけ。レイアウト、商品、コピーを前のポスターから写すことはありません。
