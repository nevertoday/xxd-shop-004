**베이커리 포스터 한 장이든 신제품 한 세트든. 크고, 가깝고, 맛있게, 한눈에 같은 가게로 보이게.**
시리즈는 먼저 키 포스터를 만들어 확인을 받고, 나머지는 그 글자·색감·가게 정체성을 이어받되 레이아웃은 장마다 바꿉니다.

| 한눈에 보기 | |
|---|---|
| **맡기는 것** | 상품 이미지 또는 상품명(여러 개 가능), 가게 이름이나 워드마크, 넣고 싶은 가격 |
| **받는 것** | 베이커리 포스터 한 장, 또는 같은 톤에 장마다 레이아웃이 다른 신제품 시리즈 |
| **스타일 특징** | 거대한 클로즈업 · 따뜻하고 밝은 아침 빛 · 브랜드 그래픽이 된 상품명 · 잡지풍 손글씨 메모 · 장마다 새로운 레이아웃 |
| **가장 잘 맞는 곳** | 빵, 케이크, 크루아상, 타르트, 쿠키, 월병. 베이커리 신제품과 시즌 시리즈 |

## 해결하는 문제

베이커리 신제품 홍보는 흔히 두 가지로 실패합니다. 한 장씩은 예쁜데 모아 놓으면 네 개의 다른 가게처럼 보이거나, 통일감은 있지만 모두 같은 템플릿에 빵만 바뀐 것처럼 보입니다.

**Shop 004**의 규칙: **포스터마다 레이아웃은 바꿔도 되지만, 글자의 성격·색감·브랜드 정체성은 공유한다.**

포스터 한 장에도 씁니다. 상품은 크고 가깝게, 가장 먹음직스러운 식감(결, 기공, 늘어남, 흘러내리는 속, 아이싱)을 새벽 빵집 진열창 같은 빛 속에서 확대합니다.

## 시리즈는 이렇게 만듭니다

1. 상품을 한꺼번에 줍니다. 사진 여러 장, 폴더, 또는 이름 몇 개.
2. 스토리보드를 씁니다. 한 품목에 한 장, 저마다 다른 레이아웃(뒤의 거대한 글자, 세로 쌓기, 특대 상품 하나, 흩어진 무리, 가장자리에서 들어오는 재료…)으로, 같은 것을 연달아 쓰지 않습니다. 각 품목의 맛, 가격, 스티커는 그 품목만의 것입니다.
3. 스토리보드와 첫 포스터를 함께 보고 글자, 색, 가게 정체성을 확인합니다.
4. 나머지가 이어집니다. 키 포스터의 글자 성격, 색감, 정체성을 이어받습니다.

상품 하나로도 세트를 만들 수 있습니다. 포스터마다 그 상품에 실제로 있는 식감을 보여 줍니다. 키 포스터가 어긋나면 그것만 다시 만들기 때문에 뒤의 이미지가 실수를 물려받지 않습니다.

## 준비할 것

- **상품 이미지 또는 상품명**(필수): 사진이 있으면 단면과 속은 사진대로, 아무것도 더하지 않습니다.
- **가게 이름이나 워드마크**(시리즈라면 강력 권장): 시리즈를 하나로 묶어 줍니다.
- **가격·"매일 굽는"·수상·개업 연도**(선택): 말했을 때만 넣습니다.

## 사용 방법

### 1단계: 설치 (한 번만)

```bash
git clone https://github.com/nevertoday/xxd-shop-004.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-004" ~/.claude/skills/xxd-shop-004
```

Codex 사용자는 같은 폴더를 `~/.codex/skills/xxd-shop-004`에 링크하세요. 설치 후에는 AI 어시스턴트 세션을 다시 시작합니다.

### 2단계: 원하는 것을 평소 말로 말하기

```text
/xxd-shop-004 피스타치오 흘러내리는 크루아상. 3:4 포스터를 만들어 줘
/xxd-shop-004 ~/Desktop/autumn-launch 안의 신제품 네 개를 시리즈로. 가게 이름은 Maiye Bakery
/xxd-shop-004 상품은 얼그레이 시폰 하나뿐. 3장 세트로, 장마다 다른 식감을 보여 줘
```

외울 플래그는 없습니다. 사이즈나 장수처럼 정하지 않은 것은 한 번에 모아서 묻고, 다음에는 지난 설정을 다시 쓸 수 있습니다.

### 3단계: 그다음에 하는 일

1. 상품 이미지와 설명을 읽고 아직 정해지지 않은 것만 묻습니다. 사이즈는 용도에 맞춰 픽셀 크기와 함께 추천합니다.
2. 시리즈는 먼저 스토리보드와 키 포스터를 보여 드리고, 확인한 뒤에 나머지를 만듭니다.
3. 사이즈마다 새로 구도를 잡고, 다른 이미지에서 잘라내지 않습니다.
4. 납품 전에 한 장씩 확인합니다. 상품이 바뀌지 않았는지, 철자가 맞는지, 주지 않은 숫자가 있는지. 통과하지 못한 것은 알리고 다시 만듭니다.
5. PNG를 `~/Desktop/xxd/xxd-shop-004/` 아래 새 작업 폴더에 저장하고 경로를 알려 줍니다.

## 자주 묻는 질문

**베이커리가 아닌 상품에도 되나요?**

베이커리용으로 만들어졌습니다. 다른 카테고리는 [001](https://github.com/nevertoday/xxd-shop-001)이나 [009](https://github.com/nevertoday/xxd-shop-009)를 써 보세요.

**무엇이 필요한가요?**

세 가지입니다. ① Claude Code나 Codex처럼 Skills를 지원하는 AI 어시스턴트. ② 이미지를 생성할 수 있는 모델: 어시스턴트에 내장된 이미지 생성, 또는 Codex에 설정한 모델 제공자로 Responses API를 통해 이미지를 생성하는 것(기본 GPT Image 2). ③ Pillow가 설치된 Python 3.11 이상(`pip install pillow`).

**비용이 드나요? 상업적으로 써도 되나요?**

Skill은 무료로 내려받을 수 있고, 이미지 생성 비용은 본인의 모델 계정에 청구됩니다. 이 프로젝트는 PolyForm Noncommercial 라이선스입니다. 개인 학습·연구·테스트는 괜찮지만, 쇼핑몰 운영, 외주 납품 등 상업적 사용은 먼저 작성자의 서면 허가가 필요합니다. 맨 아래 "라이선스"를 참고하세요.

**이미지는 얼마나 큰가요?**

비율이나 정확한 픽셀을 요청할 수 있습니다. 실제 크기는 모델이 돌려준 그대로이며 몰래 업스케일하지 않고, 파일 이름에 실제 픽셀이 적힙니다.

**이미지 속 글자에 오타가 생기나요?**

AI 이미지는 가끔 철자를 틀리거나 브랜드 이름 옆에 ® 같은 작은 기호를 덧붙입니다. 납품 전에 한 장씩 확대해 확인하고, 통과하지 못하면 다시 만듭니다. 이 페이지의 예시는 모두 그 확인을 통과했습니다.

**가격이나 판매량을 지어내나요?**
